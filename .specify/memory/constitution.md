# Constitución de vianda-tech-front-web

## Identidad del proyecto

**vianda-tech-front-web** es una página web para la compañía **Vianda Tech**, una empresa de tecnología que desarrolla páginas web y automatiza procesos con IA para empresas.

## Restricciones técnicas

- HTML y CSS puros; la menor cantidad posible de JavaScript y de frameworks.
- Referencia de look and feel: spec 006 (distribución de secciones) y spec 001 (paleta azul, minimalista, tecnológica).

## Metodología

El proyecto sigue **Spec-Driven Development (SDD)**: las especificaciones son la fuente de verdad y el código se deriva de ellas. Las especificaciones se iteran de forma incremental antes y durante la implementación.

## Principios

1. **La especificación manda**: todo cambio funcional se define primero en una especificación; el código no debe contradecirla.
2. **Iteración**: las especificaciones evolucionan en ciclos cortos y se refinan junto con el equipo.
3. **Trazabilidad**: cada pieza de implementación debe poder relacionarse con una especificación.

## Pendiente de definir

Se completará iterativamente: stack tecnológico, estándares de calidad, diseño/identidad visual, accesibilidad y SEO, y estrategia de pruebas.
